# ¿Real o Inventado?

> Te muestro una palabra rara con tres definiciones y solo una es verdadera; tú adivinas cuál.

## Qué hace y cómo se usa

Presenta una palabra rara con tres definiciones para que elijas cuál es la verdadera.
Elegí una opción con un botón o con las teclas 1, 2 y 3; usá Enter para continuar.
Al final muestra el resultado y permite repasar las palabras falladas o jugar otra vez.

## Abrir el juego

https://nataliacruz04.github.io/real-o-inventado/

## Cómo ejecutarlo en otra máquina

```sh
git clone https://github.com/nataliacruz04/real-o-inventado.git
cd real-o-inventado
npm install
npm run dev
```

Después, abrí en el navegador la dirección local que indique Vite.
